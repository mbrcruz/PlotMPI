## Naming Conventions

**Files:**
- Python modules: lowercase with underscores: `MyPlot.py` (exception: camelCase following Visual Studio conventions)
- Notebooks: PascalCase: `PlotResults.ipynb`
- Configuration: lowercase: `requirements.txt`, `.gitignore`

**Directories:**
- Package directories: PascalCase (VS convention): `PlotResults/`
- Hidden metadata: dot-prefix: `.venv/`, `.idea/`, `.git/`, `.planning/`

**Classes:**
- PascalCase: `MyPlot` (line 21), `TypeEvaluation` (line 14)

**Methods and Functions:**
- camelCase (leading lowercase): `load_data()`, `computerMetrics()`, `plotBandwidth()`, `PlotHistogram()` (exception: capital P)
- Utility methods: `random_color()`, `show_config()`, `escreveCsv()`

**Instance Variables:**
- camelCase: `self.number_nodes`, `self.df_vec`, `self.base_directory`, `self.records`
- Prefixed descriptors: `self.df_*` for DataFrames, `self.X1-X4` for scenario dicts
- Private/internal: No underscore prefix convention used; all public

**Enum Values:**
- UPPERCASE_WITH_UNDERSCORES: `JUST_SEND`, `JUST_COMUNICATION`, `COMUNICATION_AND_IO`

## Where to Add New Code

**New Feature (analysis method):**
- Primary code: Add method to `MyPlot` class in `PlotResults/MyPlot.py`
  - For loading/parsing: extend `load_data()` or create new `load_*()` method
  - For metrics: extend `computerMetrics()` or create new `compute*()` method
  - For visualization: create new `plot*()` method following pattern of lines 296–568
- Tests: Not present; no test directory to add to

**New Entry Point (different use case):**
- Implementation: Create new `.py` file in `PlotResults/` directory or new `.ipynb` notebook
- Pattern: Import `MyPlot`, instantiate with parameters, call methods sequentially
- Configuration: If hardcoded paths needed, define at module level (lines 6 in PlotResults.py)

**Utilities (shared helpers):**
- Shared functions: Add to `MyPlot` class as static methods or module-level functions at top of `MyPlot.py`
- Color management: Extend `random_color()` method (lines 62–65)
- Data validation: Add static methods to `MyPlot` for preprocessing before `load_data()`

**Configuration/Experiment Data:**
- Benchmark results: Store in subdirectories at `{base_directory}/{experiment_number}/`
  - Expected structure: `{base_directory}/1/`, `{base_directory}/2/`, etc.
  - Log files per rank: `mpiio-{rank}.log`, `sddptimer{rank:04d}.log`, `mpiio-open-{rank}.log`
- Aggregated metrics: Written to `{base_directory}/../plot.csv` (parent directory)
  - One row per `MyPlot.computerMetrics()` call
  - Indexed by `Nodes` column for plotting
